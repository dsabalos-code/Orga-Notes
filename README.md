Not-o Worri-es

Project Overview

Not-o Worri-es is a digital notebook designed to help users create, store, and organize their notes digitally. It will include a built-in arithmetic calculator so that the users can perform basic calculations without leaving the application.


Quarter 1 — Project Proposal / Conceptualization

The Planned Features

- Creates and saves notes
- View  again saved notes
- Edit the notes
- Delete the notes
- Organize the notes
- Built-in calculator (arithmetic)
- Basic input validation

Planned Technologies

- Python 
- GitHub
- JSON for data storage
