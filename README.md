Orga-Notes
Project Overview

Orga-Notes is a digital notebook designed to help users create, store, and organize their notes digitally. It will include a built-in arithmetic calculator so that users can perform basic calculations without leaving the application.

Project Status

Quarter 1 — Project Proposal / Conceptualization

Planned Features

- Create and save notes
- View saved notes
- Edit notes
- Delete notes
- Organize notes
- Built-in arithmetic calculator
- Basic input validation
- Input dates for scheduled events or descriptions

Planned Technologies

- Python
- GitHub
- JSON for data storage

How to Run / Requirements

Requirements

- Python 3
- A Python-compatible code editor or terminal
- A computer capable of running Python

How to Run

1. Download or clone the project repository.
2. Open the project folder.
3. Run the Python program.
4. Follow the instructions displayed by the program.

Note: The project is currently in the planning and early development stage, so the instructions may be updated as development continues.
